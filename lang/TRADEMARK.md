# Mycel name and logo

Mycel's code is open source (Apache-2.0 OR MIT, see `LICENSE`). The name
"Mycel" and the Mycel logo are not covered by those licenses. They belong to
drky and identify the official Mycel project and its releases.

**Fine without asking**

- Saying "Mycel" to refer to the language: writing about it, teaching it,
  making courses, videos, books, talks and blog posts about it.
- Saying your program is "written in Mycel" or that your tool "works with
  Mycel" or "supports Mycel".
- Naming a library or package for Mycel, as long as it does not look official
  (`mycel-json` by you is fine; "Official Mycel JSON" is not).
- Shipping an unmodified official release and calling it Mycel.

**Forks**

Forks are welcome. A fork that changes the compiler, the standard library or
the editor plugins must use a different name and a different logo, so nobody
mistakes it for the official project. It should say it is "based on Mycel" (or "a fork of Mycel")
with a link to https://ol1x.xyz/mycel, and it must keep the NOTICE file.

**Ask first**

- Using the name or logo for a product, company, domain or app-store listing
  that could look like it comes from the Mycel project.
- Changed versions of the logo.

Open an issue to ask. This note is a plain-language policy, not a license; it
does not limit anything the Apache-2.0 or MIT license lets you do with the code.
