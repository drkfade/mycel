Start your first program

Create hello.myc containing print("hi"), then run: mycel hello.myc (or myc hello.myc)

Or run mycel new demo, cd demo, mycel run and mycel test.

If the command is not found, add /usr/local/bin to your shell's PATH.

Learn: ol1x.xyz/mycel/learn/

Read /usr/local/share/mycel/README.txt for alpha limits and uninstall instructions.
